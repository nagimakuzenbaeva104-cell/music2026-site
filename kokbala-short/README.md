# Көкбала: балалар әндеріне арналған Shorts анимациясы

Remotion (React) жобасы. Барлық кейіпкер SVG-мен салынған, сондықтан әр кадрда бірдей көрінеді.

## Композициялар

| ID | Видео | Дыбыс | Ұзақтығы |
|---|---|---|---|
| `KokbalaShort` | Автобустың дөңгелегі, 1-бөлім (дөңгелек, есік, сүрткіш, шам, сигнал) | `public/song.mp3` | 46 сек |
| `KokbalaShort2` | Автобустың дөңгелегі, 2-бөлім (мотор, жолаушылар, бөпе, ана, әже, әке) | `public/song2.mp3` | 57 сек |
| `KokbalaBlueBus` | The Happy Blue Bus (ағылшынша) | `public/bluebus.mp3` | 61 сек |
| `KokbalaAuyl` | Көкбала ауылда: «Бұл кім?» ойыны (қой, сиыр, жылқы, әтеш) | `public/auyl.mp3` | 63 сек |

Барлығы: 1080×1920 (9:16), 30 fps.

## Іске қосу

```bash
npm i
npx remotion studio                       # браузерде алдын ала қарау
npx remotion render KokbalaShort out.mp4  # рендерлеу
```

Chromium жүктей алмайтын ортада: `--browser-executable=<chrome-headless-shell жолы>`.

## Құрылымы

- `src/characters/Kokbala.tsx`: Көкбала автобусы, Әлия (кеуде бөлігі), қой, түстер палитрасы `C`
- `src/characters/People.tsx`: әже, ана мен бөпе, әке, қалпақ киген жолаушы, толық бойлы Әлия, жүрекше
- `src/shared.tsx`: аспан, қала, аялдама, жаңбыр, караоке мәтін, Nunito қаріпі (жергілікті файлдан жүктеледі)
- `src/characters/Animals.tsx`: сиыр, жылқы, әтеш
- `src/KokbalaAuyl.tsx`: ауыл фоны (киіз үй, қоршау, дала жолы) және көлеңкеден ашылатын «Бұл кім?» сахнасы
- `src/BusInterior.tsx`: автобустың іші (камерамен жақындату мүмкіндігі бар)
- `src/timeline*.ts`: әр видеоның мәтін жолдары мен сахналарының уақыты
- `tools/`: Whisper арқылы әннің мәтінін уақытымен анықтау скрипттері (`words2.py` қазақша, `words2_en.py`/`words_en.py` ағылшынша), `make_music.py` аспаптық әуенді синтездейді

## Жаңа әнмен жаңа видео жасау

1. Әнді `public/` папкасына салыңыз (қажет болса ffmpeg-пен қиыңыз).
2. Уақыттарды анықтаңыз: `HF_HUB_DISABLE_XET=1 python3 -I tools/words2.py song16k.wav 0-30 28-60`
   (алдымен 16 kHz моно WAV-қа айналдырыңыз).
3. `src/timelineN.ts` файлын жасаңыз (`LINES`: `{ t, text, sound? }`, `\n` жаңа жолға көшіреді).
4. Бар композицияны көшіріп, сахналарды өзгертіңіз де, `src/Root.tsx` ішіне тіркеңіз.

Whisper уақыттары шамамен алынады, кей жолдарды (мысалы «Тсс») қолмен қою керек. Айтылымды міндетті түрде құлақпен тексеріңіз.
