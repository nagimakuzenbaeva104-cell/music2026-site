# LoveStory: «Бізді күткен таң»

Нагима Кузенбаеваның «Бізді күткен таң» әніне жасалатын 3:49 кинематографиялық махаббат клипі.

## Хикая

Қыз терезе алдында оның хаттарын оқып, күтіп жүр. Қайырмаларда махаббат естеліктері көрінеді:
жаңбырдағы танысу, кафедегі бірінші хат, шалғын. Аспаптық бөлімде олар ұрысып, вокзалда
қоштасады. 2-шумақта хат жазысады. Көпірде жігіт қайтып келеді. Финал вокзалдағы
кездесумен басталып, «бізді күткен таң» атқан шалғында аяқталады.

## Құрылым

```
LoveStory/
├── music/song.mp3          ән (git-ке түспейді)
├── videos/s01.mp4 ... s54  Google Flow-дан алынған кадрлар (git-ке түспейді)
├── images/characters/      кейіпкер референстері
├── scenes/
│   ├── characters.md       кейіпкерлер, локациялар, түс. МІНДЕТТІ БІРІНШІ ҚАДАМ
│   ├── shots.csv           54 кадр: уақыт, ән сөзі, камера, промпт (негізгі файл)
│   ├── tokens.json         кейіпкер, локация, стиль сипаттамалары
│   ├── storyboard.md       дайын промпттар (shots.csv-дан жасалады)
│   └── beats.json          әннің биттері
├── tools/build.py          монтаж скрипті
└── output/                 дайын клип
```

## Жұмыс тәртібі

1. `scenes/characters.md`: кейіпкер суреттерін жаса, ұнағанын бекіт.
2. `scenes/storyboard.md`: әр кадрдың промптын Google Flow-ға бер, ең жақсы нұсқаны
   `videos/sNN.mp4` деп сақта.
3. Тексеру және жинау:

```bash
python3 tools/build.py check                    # не жетіспейді
python3 tools/build.py render --preview --snap  # жылдам нұсқа 960x540
python3 tools/build.py render --grade --snap    # финал 1920x1080
```

Видеосы жоқ кадрдың орнына сипаттамасы жазылған сұр экран қойылады. Сондықтан ритмді
бірінші видео дайын болмай тұрып-ақ тексеруге болады.

## Мудфильм (тизер, ~47 с)

Клип шыққанға дейін аудиторияны қыздыратын қысқа атмосфералық ролик. **Жаңа кадр
генерациялау керек емес**: ол клиптің 13 кадрынан құралады, `scenes/moodfilm.csv`-да тұр.

- Ән `1:22`-ге дейін, `0:35.7`-ден («Үмітімнің оты әлі сөнбейді») басталып, бірінші
  қайырманың соңында сөнеді.
- Сағыныш (cold) пен естелік (warm) кезектеседі. **Кездесу мен финал әдейі жоқ**: олар
  клипке сақталады. Соңында «Бізді күткен таң / жақында» атауы.
- **Жасау парағы:** `scenes/moodfilm_prompts.md`. Онда 4 референс суреттің промпты және 13 кадр жасау ретімен тұр.
- Кадр ауыстыру, ұзақтығын өзгерту үшін тек `moodfilm.csv`-ны өзгерт. Бірінші жол
  әннің қай жерден басталатынын анықтайды.

```bash
python3 tools/build.py mood --preview                    # жылдам тексеру 960x540
python3 tools/build.py mood --grade --snap               # YouTube 1920x1080
python3 tools/build.py mood --grade --snap --vertical    # Shorts/Reels/TikTok 1080x1920
```

**Тік нұсқа туралы:** 16:9 кадрдан 9:16 кесілгенде ені үштен бірі ғана қалады.
Екі адам қатар тұрған кадрларда (s13, s21) біреуі кадрдан шығып кетуі мүмкін.
Сондай кадрда `focus` бағанын өзгерт: `0` сол жақ, `0.5` орта, `1` оң жақ.
