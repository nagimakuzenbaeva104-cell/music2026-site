# LoveStory

Музыкалық бейнеклип жобасы.

## Құрылым

```
LoveStory/
├── music/    # Әннің аудио файлы (song.mp3)
├── videos/   # Бастапқы бейне фрагменттер (AI-генерация, түсірілімдер)
├── images/   # Суреттер, кадрлар, референстер, обложка
├── scenes/   # Сахна сипаттамалары, промпттар, сценарий
├── output/   # Дайын рендер (финалдық клип)
└── README.md
```

## Жұмыс тәртібі

1. `music/song.mp3` — әнді осында сал.
2. `scenes/` — әр сахнаға жеке файл: уақыт кодтары (мыс. `00:00–00:15`), сипаттама, AI промпт.
3. `images/` және `videos/` — сахналарға арналған материалдар.
4. `output/` — финалдық бейне.

## Ескерту

Ауыр медиа файлдар (`.mp3`, `.mp4`, `.mov`, `.wav`) git-ке commit жасалмайды —
`.gitignore` арқылы өткізіледі. GitHub 100 MB-тан үлкен файлды қабылдамайды.
Медианы сақтау үшін Git LFS немесе Google Drive қолдан.
