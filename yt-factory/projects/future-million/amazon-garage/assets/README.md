## Правила

1. **Имена файлов** — строго как в таблице; движок подхватит их сам. Видео/фото в git не попадают.
2. **Лицензия.** Перед скачиванием откройте страницу источника и прочитайте раздел Licensing. Финальный рендер с любым загруженным файлом 🟡/🔴 заблокирован, пока вы не прочитаете лицензию на странице и не поменяете `license_status` на `verified` в `scenes.yaml`.
3. **Ссылки на источники** уже записаны в `scenes.yaml`; титры для описания YouTube — в `yt-output/.../credits.txt` (CC BY / CC BY-SA требуют указать автора и лицензию).
4. **Не выдавать других людей за Безоса.** На иллюстрациях — никаких лиц, которые можно принять за него. Его лицо — только на реальных фото с подписью года.
5. **Год в кадре.** Фото не из того года, о котором говорит диктор, всегда с подписью года.
6. **Чужие видео** (CNET, KIRO 7, ABC7, CBS, C-SPAN, YouTube-перезаливы) — не использовать: это не свободные лицензии; для монетизируемого канала нужна платная лицензия.
7. **Формат:** 9:16 от 1080×1920 для «на весь экран»; горизонтальное видео обрежется до центральной трети. Hero-цифра — 30–46% высоты, субтитры — 57–72%: лица и важные объекты держите вне этих полос.
8. **Музыка:** `assets/music.mp3` (YouTube Audio Library). Без файла — без музыки.
