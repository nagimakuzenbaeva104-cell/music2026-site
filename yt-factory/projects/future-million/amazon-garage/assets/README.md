# Кадры для «Amazon started in a garage»

Файл сгенерирован командой `storyboard` — правьте сценарий (`scenes.yaml`), а не этот файл.

## Как добавить кадр

1. Назовите файл по номеру сцены: `s01.mp4`, `s02.jpg` … (mp4/mov/webm или jpg/png/webp).
2. Положите его в эту папку `assets/`. Движок подхватит его сам.
3. Музыка: `music.mp3` в эту же папку (YouTube Audio Library). Без файла — видео без музыки.
4. Видео и аудио из `assets/` в git не попадают (`.gitignore`).

## Требования ко всем кадрам

- **Формат:** вертикальный 9:16, от 1080×1920. Горизонтальный 16:9 тоже можно, но в кадр попадёт только центральная треть ширины (≈32%) — главный объект должен быть в центре.
- **Свободные зоны:** 30%–46% высоты — крупная цифра (hero), 57%–72% — субтитры. Лица и важные объекты в этих полосах будут закрыты текстом. Низ кадра (~25%) и правый край перекрывает интерфейс YouTube.
- **Стиль:** тёмный, кинематографичный, тёплый свет (золото/янтарь) и холодные синие тени — под палитру канала. Медленное движение камеры, без резких рывков.
- **Без реальных людей сюжета:** не используйте кадры, где можно принять человека за Джеффа Безоса, и не генерируйте его лицо. Только символические кадры (город, гараж, книги, биржа).
- **Не случайные кадры:** каждый клип должен показывать то, о чём говорится в сцене.
- **Лицензия:** только кадры, которые вы вправе использовать (Pexels License, свои съёмки).
  Сохраняйте ссылку на источник каждого клипа — пригодится при споре по авторским правам.

## Детали по сценам

### s01 — Ночной Манхэттен, окна офисных башен

- В кадре звучит: «In nineteen ninety-four, Jeff Bezos quit his job as a vice president on Wall Street.»
- На экране: hero **1994** + субтитры «In 1994, Jeff Bezos quit his job as a vice president on Wall Street.»
- Длина клипа: не меньше **5.2 с** (лучше 6+ с; короче — будет зациклен)
- Поиск (Pexels / свой архив): `manhattan night office`
